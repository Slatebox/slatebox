# Getting help

| You want to | Go to |
| --- | --- |
| Ask a question or get help with a setup | [Slatebox support](https://support.slatebox.com): our [GitHub Discussions](https://github.com/Slatebox/slatebox/discussions), [Q&A](https://github.com/Slatebox/slatebox/discussions/categories/q-a) |
| Read guides and reference | [docs.slatebox.com](https://docs.slatebox.com): the app, self-hosting, the engine, the API and the MCP server |
| Suggest an idea | [Ideas](https://github.com/Slatebox/slatebox/discussions/categories/ideas) |
| Report a bug | [Open an issue](https://github.com/Slatebox/slatebox/issues/new/choose) |
| Report a security problem | [A private report](https://github.com/Slatebox/slatebox/security/advisories/new) (see [SECURITY.md](SECURITY.md)) |
| Ask about your account, privately | [slatebox.com/contact](https://slatebox.com/contact/) |

Before you ask, a quick search of the docs and of earlier discussions often finds the answer.
When you ask, say what you are trying to do, what you tried, and what happened, with versions:

- Self-hosted: the image tag (`docker inspect slatebox --format '{{.Config.Image}}'`)
- Installer: `npx slatebox --version`
- MCP server: `npm ls -g slatebox-mcp`

Slatebox is maintained by a small team. Discussions are answered by maintainers and by the
community, in the open, so the answer helps the next person too.
