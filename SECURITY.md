# Security

Report a security problem in Slatebox, Slatebox Cloud (app.slatebox.com), its MCP server
(`https://app.slatebox.com/mcp` and the `slatebox-mcp` package) or the API by email to
tim@slatebox.com, with "Security" in the subject. Please do not open a public issue for it.

Say what you found, how to reproduce it and what it lets someone do. We answer, keep you
posted while we fix it, and credit you when the fix ships unless you would rather we didn't.

Only test against your own account and slates, or a Slatebox you run yourself. Do not read
or change other people's data, and do not degrade the service for others.
